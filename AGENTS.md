# AGENTS.md

Boutique-resort marketing site: hand-written HTML/CSS/vanilla JS (no framework), bundled by Vite, deployed to GitHub Pages. A Cloudflare Worker (`worker/`) and a Google Sheet act as the "backend".

Read [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) first (diagrams, data flow, "change X → touch this" cheat-sheet), then [`README.md`](README.md) and [`worker/README.md`](worker/README.md). This file only lists what those don't emphasize.

## Commands & verify order

- `npm run dev` — Vite dev server, port 5173, `base` is `/` in dev.
- Verification order (what CI runs): `npm run i18n:lint` → `npm test` → `npm run build`.
- `npm test` needs the Worker's deps installed first or worker tests fail (`ERR_MODULE_NOT_FOUND`): `cd worker && npm ci`.

## Test gotchas (agent traps)

- No test framework — Node built-in `node:test` with plain `.test.mjs` files.
- Root `npm test` is an **explicit file list** in `package.json`. A NEW test file silently won't run unless you add it to that list.
- `scripts/__tests__/i18n-smoke.test.mjs` runs `npm run build` whenever `dist/` is stale; set `SKIP_SMOKE_BUILD=1` to skip (e.g. while a `vite build --watch` is running).
- `i18n:lint` is NOT part of `npm test` — run both.

## i18n is build-time, not runtime (the big gotcha)

- EN serves at `/`, BG at `/bg/`. Translation is baked at build by `scripts/i18n-plugin.js`; a language change is a full navigation to the mirror URL.
- **Any visible text change requires editing BOTH `locales/en.json` and `locales/bg.json` with identical key sets.** Dropped/mismatched keys fail `i18n:lint` and the build.
- Keys prefixed `_note` are intentionally orphan (metadata for editors).
- NO `data-i18n*` attribute may survive into `dist/` — a smoke test enforces this.
- Exceptions hardcoded in JS and NOT dict-wired: `/stay/` price-pill labels and other runtime strings.
- Adding a page? Must be registered in `INPUTS` in `vite.config.js` (shared with the plugin, which emits the BG mirror from the same list) and the site has no shared layout primitive — header/footer are duplicated per page with `KEEP IN SYNC` HTML comments listing all entries; update them all.
- `vite.config.js` `i18nContext` duplicates `assets/js/site-config.js` values and must be kept in lockstep (head-metadata/no-JS paths only see the build-time value).

## The Google Sheet is the database

- Owner edits the Sheet; the Worker reads the Offers + rate-table + B1/B2/B3 availability tabs and appends enquiry rows.
- **Sheet schema is out-of-band from Worker code.** Changing the column layout in `worker/src/sheets.js` REQUIRES a manual header-row update on the "Enquires" tab BEFORE deploying, or data lands in unlabelled columns with no automated check (see README's deploy checklist).
- `public/assets/data/bookings.json` is GENERATED by `scripts/fetch-bookings.mjs` at deploy time — gitignored, never hand-edit. Stale availability means the sheet or the cron refresh job is wrong.

## Cloudflare Worker (`worker/`)

- Separate npm package (`jose` + `wrangler`). Routes: `GET /offers`, `POST /price`, `POST /submit` (form action), everything else 404s.
- Secrets via `wrangler secret put` (never committed); template at `worker/.dev.vars.example` → copy to `.dev.vars` for local dev.
- Deploys on push to `main` when `worker/**` changes.

## Conventions

- Branch → PR → squash-merge to `main`; never push straight to `main`. CI cancels stale runs per branch.
- `dist/` and `node_modules/` are gitignored; a clean-verified command order is `npm run i18n:lint && npm test && npm run build`.
- Pre-commit hook `scripts/check-no-secrets.sh` scans staged diffs for credentials; install as `.git/hooks/pre-commit` (bypass `git commit --no-verify` only after review).
- `docs/ARCHITECTURE.md` diagrams are contract: if you change a flow, update the matching diagram in the same PR.
